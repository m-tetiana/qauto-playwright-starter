# Вимога: додавання автомобіля

## Початковий стан

- Користувач відкрив QAuto та увійшов через `Guest log in`.
- Після входу ліве бокове меню з пунктом `Garage` відкрите за замовчуванням.

## Сценарій

1. Натиснути кнопку `Add car`.
2. У полі Brand обрати `Audi`.
3. У полі Model обрати `TT`.
4. У полі Mileage заповнити `12000`.
4. Натиснути кнопку `Add`.

## Очікуваний результат

- Відображається картка доданого авто.
- Відображається логотип авто.
- Відображається назва бренду `Audi`.
- Відображається назва моделі `TT`.
- Відображається іконка `Edit`.
- Відображається кнопка `Add fuel expense`.
- Відображається поле з вееденим значенням пробігу `12000`.
- Кнопка `Update` неактивна.

## Межі

- Model залежить від Brand.
- Точні HTML-атрибути й CSS-класи не задані.
- Ознаки елементів треба підтвердити за поточним UI.
- Якщо неможливо вибрати бренд `Audi` та модель `TT`, треба зафіксувати blocker, а не вигадувати успішний результат.
